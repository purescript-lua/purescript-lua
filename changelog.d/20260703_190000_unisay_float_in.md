### Changed

- Added an IR-level float-in pass: a `let`-bound value used in only one
  branch of an `if` is now sunk into that branch instead of being
  evaluated unconditionally above it. This replaces the Lua-AST rule
  `pushDeclarationsDownTheInnerScope`, disabled in #137 because it sank
  a declaration into the body of the *returned* lambda, re-evaluating it
  on every call and losing sharing. The new pass runs at the IR level,
  where lambdas are visible as distinct nodes, so it can rule out that
  shape directly: a binding is never sunk across a lambda (#136).
